# GarageGo - UI/UX Prototypes

This repository contains the exported Figma designs for **GarageGo**, a vehicle service platform that connects customers, mechanics, garage owners, and administrators through a centralized system. The exports are organized according to the different user roles supported by the platform.

## Repository Structure

```text
figma-exports/
├── Customer App/
├── Mechanic App/
├── Admin Page/
└── GarageOwner Page/
```

Each folder contains the corresponding Figma exports for that user role.

## Description

### Customer App
Provides vehicle owners with features such as service booking, emergency assistance, nearby garage discovery, service tracking, notifications, and profile management.

### Mechanic App
Allows mechanics to manage assigned jobs, update service statuses, track ongoing work, view service history, and manage their profiles.

### Admin Page
Provides administrative functionalities including user management, garage management, mechanic management, reports, analytics, and system monitoring.

### Garage Owner Page
Enables garage owners to manage garages, mechanics, service requests, business operations, service records, and performance monitoring.

## About GarageGo

GarageGo is a vehicle service platform designed to simplify vehicle maintenance and emergency assistance by connecting customers with nearby garages and mechanics. The platform provides dedicated interfaces for customers, mechanics, garage owners, and administrators to ensure efficient service management and communication.
