# Contributing to Prototypes Repository

This repository stores UI/UX design assets including wireframes, mockups, and exported designs.

---

## Branch Strategy

- `main` → Approved designs only
- `draft/<feature-name>` → Work in progress
- `fix/<issue-number>` → Changes after review

Example:
- `draft/booking-screen`
- `draft/dashboard-ui`

---

## File Formats

- PNG (1x, 2x exports)
- PDF exports
- SVG (small icons only)
- Figma source links (preferred)

---

## Large Files

- Files > 5MB should be stored in Google Drive
- Add shared link in README or PR description

---

## Commit Messages

- `feat:` Add new screen or UI component
- `style:` Visual updates (colors, spacing, layout)
- `docs:` Export or update design documentation
- `fix:` Fix UI issues from review

Examples:
- `feat: add booking confirmation screen`
- `style: update dashboard layout`
- `docs: export figma wireframes`

---

## Pull Request Rules

- Must include screenshots or previews
- At least 1 approval required
- Do not merge your own PR
- Explain design decisions in PR description

---

## File Naming

- `login-screen-wireframe.png`
- `booking-flow-v2.pdf`
- `dashboard-ui-export.png`
